# ifield-chat
Private P2P E2E encrypted chat. No accounts, no logs.
# 🔐 iField — Приватный P2P Чат

**iField** — это Telegram Mini App для анонимного и защищенного общения. Никаких серверов, никаких логов, никакой истории. Только ты и твой собеседник.

## 🛡️ Главные фичи
- **E2E Шифрование:** Все сообщения шифруются алгоритмом AES-256-GCM (с генерацией ключа через SHA-512).
- **P2P Соединение:** Сообщения идут напрямую с устройства на устройство (WebRTC). Сервер (Cloudflare) используется только для первичного «рукопожатия» и стирает данные через 5 минут.
- **Режим Самоликвидации (🔥):** Сообщения бесследно исчезают через 10 секунд после прочтения.
- **Кнопка Паники (💥):** Мгновенно стирает всю историю чата и ключи шифрования, если рядом кто-то посторонний.
- **Скрытый ключ:** Ключ доступа на экране хоста скрыт под звездочками.
- **Донаты (Telegram Stars):** Возможность поддержать проект звёздами прямо внутри приложения.

## ⚙️ Технологии
- **Фронтенд:** Чистый HTML/CSS/JS без сторонних библиотек (все в одном файле `index.html`).
- **Бэкенд:** Cloudflare Workers (Serverless).
- **База данных:** Cloudflare KV (для временного хранения сигналов связи).
- **Интеграция:** Telegram WebApp API (Haptic Feedback, Invoice, Themes).

## 🚀 Как пользоваться
1. Откройте бота в Telegram.
2. Нажмите **«Создать комнату»**. Сгенерируются код и секретный ключ.
3. Передайте их другу любым удобным способом (лучше всего — голосом или в другом мессенджере).
4. Друг нажимает **«Войти по коду»** и вводит данные.
5. Общайтесь! Канал зашифрован.

## ⚠️ Важно о приватности
В P2P-сетях ваш IP-адрес технически виден собеседнику. Для максимальной анонимности используйте надежные VPN или отключайте STUN-серверы в настройках (режим локальной сети).
